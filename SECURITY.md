# Security reporting

Do not post credentials, MD5 password equivalents, tokens, local session keys,
private inventories, IPs or packet dumps in public issues. Use GitHub's private
vulnerability reporting if enabled for this repository; otherwise contact the
maintainer privately through their GitHub profile before sharing sensitive
details. Rotate exposed credentials and review HA backups.

Read the README security section for vendor protocol limitations and stored
credentials. This integration cannot add TLS/authenticated integrity to the
gateway's existing local protocol.
